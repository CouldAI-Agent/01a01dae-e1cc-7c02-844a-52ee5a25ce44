# Gamer Angel Profile

A beautiful, responsive Flutter app showcasing the profile, game history, and stats of a celestial "Gamer Angel." This app features a blend of angelic aesthetics with cyberpunk gaming elements.

## Features
- **Angelic Gaming Dashboard**: View key stats like win rates, total hours, and angelic rank.
- **Game History**: Scroll through a timeline of recent games played across various realms.
- **Cross-Platform Responsive Layout**: Optimized for both mobile devices (stacked layout) and desktop/web (multi-column presentation).
- **Custom Theming**: Dark mode focused with neon accents and ethereal glows.

## Tech Stack
- Flutter (Dart)
- Material Design 3

## Setup & Run
1. Ensure Flutter is installed and configured on your system.
2. Run `flutter pub get` to fetch any dependencies.
3. Start the app with `flutter run`.

## Deployment
Can be built for Web, iOS, Android, macOS, Windows, and Linux.
